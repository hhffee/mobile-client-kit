# Проверенные функции AyuGram и статус переноса

Сверено 10 ноября 2026 по первичным источникам:

- [Android: документация](https://docs.ayugram.one/android/) и [README](https://github.com/AyuGram/AyuGram4A).
- [Desktop: документация](https://docs.ayugram.one/desktop/) и [README](https://github.com/AyuGram/AyuGramDesktop).

«Код добавлен» означает только реализацию в исходниках и подключение overlay. Без macOS-сборки и проверки на iPhone ни одна новая функция не считается подтверждённой в приложении. Весь AyuGram пока не перенесён.

| Функция | Статус iOS |
|---|---|
| Ghost Mode | Частично: код переключателей онлайна, набора/записи и прочтения чатов/комментариев добавлен. Истории и live drafts пока не перекрыты |
| История правок | Код архива текста перед правкой добавлен |
| Anti-Recall | Код отдельного текстового архива перед явным удалением добавлен; в ленте сообщения удаляются |
| Без рекламы | Код отключения загрузки и кэшированных рекламных блоков добавлен |
| Фильтр заблокированных | Не перенесён |
| AyuForward / снятие ограничений копирования и скачивания | Не перенесено |
| Local Premium | Не перенесён; серверную подписку локальные изменения не дают |
| Снимки секретных чатов/медиа | Не перенесено |
| Управление TTL-медиа | Не перенесено |
| Кэш чатов после исключения | Не перенесён |
| AyuSync | Не подключён |
| Метки правок/удалений | В новом архиве есть; в пузырях не добавлены |
| Шрифт, моноширинный шрифт | Есть настройки базового iOS-клиента; расширения AyuGram не перенесены |
| Streamer Mode | Не перенесён |
| Переводчик | Есть в базе Telegram; изменения AyuGram не переносились |
| Расширенное оформление | Не перенесено |
| Иконки | Добавлен новый основной знак; расширенный выбор не адаптирован |
| Ширина сообщений | Не перенесена |
| 100 последних стикеров | Не перенесено |
| ID профиля | Не добавлен в профиль; ID чатов есть в архиве |
| Контекстное меню | Дополнения AyuGram не перенесены |
| Отключение цветных ответов/цитат | Не перенесено |
| Скрытие похожих каналов | Не перенесено |
| Скрытие счётчиков папок / «Все чаты» | Не перенесено |
| Детали сообщения и автор пакета | Не перенесено |
| GIF-контролы | Есть базовые возможности iOS; изменения AyuGram не перенесены |
| Время служебных сообщений | Не перенесено |
| Перемотка голосовых/кружков | Есть в базовом iOS-клиенте; ещё не проверена в этой сборке |
| Уведомления сверху по центру | Не перенесены |
| Прочитать все диалоги | Есть в базе; блокируется новым переключателем прочтения |
| Просмотр/copy callback-кнопок | Не перенесён |
| Message Shot | Не перенесён |
| Material-переключатели | Не перенесены; новые настройки используют UIKit |
| Исправленные хвосты пузырей | Не перенесены |
| Значок отправителя-канала | Изменения AyuGram не перенесены |
| Скруглённые стикеры | Не перенесены |
| Секунды реакций | Не перенесены |
| Переход в начало | Изменения AyuGram не перенесены |
| Настройка поля сообщения | Не перенесена |
| Taptic / Force Click для macOS | Механики macOS; прямой перенос на iPhone не применим |
| Официальные ключи / маскировка клиента | Не копируются; необходимы собственные Telegram API-реквизиты |

Дополнительные неизвестные функции, не перечисленные авторами, не заявляются реализованными. README Android также прямо предупреждает, что часть history hooks отсутствует в публичном коде; их нельзя считать готовой переносимой библиотекой.
